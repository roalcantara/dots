Terms for the PT-BR LinkedIn posts ([PLAYBOOK.md](PLAYBOOK.md), "Language"). Code, commands, tool names, Conventional
Commit types and "RECIPE" stay in English.

| English | PT-BR | Note |
| --- | --- | --- |
| commit, branch, merge, squash merge | commit, branch, merge, squash merge | loanwords, kept |
| pull request (PR) | pull request (PR) | kept |
| changelog, release, deploy, pipeline | changelog, release, deploy, pipeline | kept |
| features and fixes | features e fixes | kept, as Brazilian devs say them |
| title (of a PR) | título | |
| Here is how I fixed it: | Veja como resolvi: | the post's pointer line |
