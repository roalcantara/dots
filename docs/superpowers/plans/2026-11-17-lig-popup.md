# Lig popup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lig's completion popup in every interactive desktop zsh, configured from the repo and themed by
`dots theme`, with fzf-tab as its fallback.

**Architecture:** Each theme folder carries a full `lig.toml`; `config/lig/config.toml` is a committed relative link
to the active theme's copy (like `config/ghostty/auto`). `.zshrc` sources cached copies of `lig init zsh pre|post`
from a new `opt/rc.d/lig.zsh` module, so no `lig` process runs at startup; `mise run zsh:lig` and bootstrap write
the cache.

**Tech Stack:** zsh, Lig 1.4 (`kevengoncalves/tap/lig`), mise inline tasks with usage, Bun specs, Homebrew Brewfile.

**Spec:** [`docs/superpowers/specs/2026-11-17-lig-popup-design.md`](../specs/2026-11-17-lig-popup-design.md)

## Global Constraints

- Branch `feat/shell-ux-theme`; no worktree, no push, no PR.
- Git only through `g() { git -c filter.sops.clean=cat -c filter.sops.smudge=cat "$@"; }`; stage named paths only.
- Commits: Conventional Commits, capitalised description, ending with
  `Co-Authored-By: DeepSeek V4.1 Flash <noreply@deepseek.com>`.
- Not yours, never stage or edit: `config/claude/settings.json`, `config/kodexb/sources/todo.yml`,
  `config/wakatime/ai-timestamps/*.json`.
- `config/zsh/.zshrc` holds two uncommitted `SPIKE (Lig, …)` blocks from the owner's spike: Task 3 replaces them;
  do not commit them as they are.
- `~/.config/lig/` is a real folder the spike created (one `config.toml`): Task 1 deletes it so the dotfiles link can
  replace it.
- Shared Lig settings, verbatim: `[behavior]` `completers = ["shell"]`, `online = false`, `history = false`.
- Desktop only: Lig goes below `return unless desktop` in the Brewfile; containers and CST stay unchanged.
- No `lig` process at shell start; a shell without Lig (not installed, `LIG_DISABLE=1`, no terminal, `zsh -c`)
  behaves as today.
- Every doc and reference updated in the task that changes the behaviour.
- `zsh:verify`, `zsh:baseline` and `zsh:bench` run under a terminal: `script -q /dev/null mise run zsh:<task>`.
- Specs run with `mise run -C test integration <domain> <stem>`.

## Review Focus

1. Lig upgraded (binary newer than the cache): the shell must start without Lig and say so in one line, never
   source a stale pre block that execs a moved binary.
2. No state link on a fresh machine: bootstrap must create it, or Lig runs with defaults (online search on).
3. `zsh -c`, scripts, specs and Docker images: never enter Lig (the pre block's own terminal guards).
4. Tab with the popup closed or empty: still fzf-tab.
5. A theme added later without a `lig.toml`: the folder spec must fail, not leave Lig unconfigured.

### Task 3: Source Lig from the cache in `.zshrc`

**Files:**
- Create: `config/zsh/opt/rc.d/lig.zsh` (`#DECLARES lig::pre lig::post`, `#ABOUT`, `#ORDER` headers like
  the other rc.d modules)
- Modify: `config/zsh/.zshrc` (replace both SPIKE blocks), `config/zsh/README.md` (module table)
- Test: `test/integration/bootstrap/lig.spec.ts`

**Interfaces:**
- Consumes: the cache files from Task 2 (`DOTS_LIG_CACHE` override).
- Produces: `lig::pre` (sourced before p10k's instant prompt), `lig::post` (last line of `.zshrc`).

- [ ] **Step 1: Write the failing tests**
- `it(".zshrc runs no lig process")`: the text of `config/zsh/.zshrc` and `opt/rc.d/lig.zsh` contains no
  `$(lig` and no `lig init`.
- `it("pre and post source the cache when it is fresh")`: in `zsh -f`, source `lig.zsh` with a fake `lig` on
  `PATH` and cache files that set `LIG_PRE_RAN=1` / `LIG_POST_RAN=1`; call `lig::pre; lig::post`; both set.
- `it("a stale cache is skipped with one line")`: touch the fake `lig` newer than the cache; both stay unset and
  stderr has exactly one line naming `mise run zsh:lig`.
- `it("no lig, no cache: silent")`: neither set, stderr empty.
- `it("an interactive shell without a terminal never enters Lig")`: the existing `env -i … zsh -ic` harness prints
  `${_lig_loaded:-none}` → `none`.

- [ ] **Step 2: Run to see them fail** → FAIL (no module).

- [ ] **Step 3: Implement**

- `lig.zsh`: cache folder `${DOTS_LIG_CACHE:-${XDG_CACHE_HOME:-$HOME/.cache}/dots/lig}`. `lig::pre`: return when
  `$commands[lig]` is unset or `pre.zsh` is missing; when `$commands[lig] -nt pre.zsh`, print once to stderr
  `lig: upgraded; run mise run zsh:lig (this shell starts without the popup)`, export `LIG_DISABLE=1` (so
  `lig::post` and child shells skip too) and return; else `source pre.zsh`. `lig::post`: same checks without the
  message, then `source post.zsh`.
- `.zshrc`: delete the SPIKE blocks; `source $zrc/lig.zsh` and `lig::pre` above the instant prompt (so `zrc` is set
  first: move the `zrc=` line up, or source by full path; keep the manifest style), `lig::post` after `unset zrc`
  (call before unsetting if it needs `zrc`). `LIG_LOG` is not set anywhere.
- `config/zsh/README.md`: a row for `lig.zsh`.

- [ ] **Step 4: Run to see them pass**, then `script -q /dev/null mise run zsh:verify` (syntax OK; parity will
  differ by the `_lig_*` names and `lig::*`, expected until Task 4's baseline).
