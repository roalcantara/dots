# DESIGN: `xc-fabric` Usage CLI Migration

## 1. Overview & Goals

Migrate **`config/bin/xc-fabric`** (the interactive Fabric pattern runner) from legacy docopt `##?` headers and `xc-usage` parsing to the **`usage` CLI shebang pattern** (`#!/usr/bin/env -S usage zsh`).

### Goals

1. **Usage CLI Shebang**: Shebang `#!/usr/bin/env -S usage zsh` with `#USAGE` annotations for subcommands (`run`, `ls`, `update`, `show`, `strategies`, `scrape`), global flags, metadata (`version`, `about`), and examples.
2. **Remove `zparseopts` and `##?` headers**: Replace manual flag and docopt parsing with native `$usage_*` environment variables auto-populated by `usage zsh`.
3. **Subcommand `--help`**: Native support for subcommand help (`xc-fabric run --help`, etc.) generated by the `usage` engine.
4. **Shell Completion**: Automatic zsh auto-completion for `xc-fabric`, its subcommands, and flags via `completion-init`.

## 2. Architecture & Component Roles

```
┌───────────────────────────────────────────────────────────┐
│                 User Invokes xc-fabric                    │
└─────────────────────────────┬─────────────────────────────┘
                              │
               (usage zsh shebang parses args)
                              │
     ┌────────────────────────┴────────────────────────┐
     ▼                                                 ▼
[xc-fabric --help / run --help]          [xc-fabric run / ls / show / ...]
  Auto-generated help via usage            Subcommand body reads $usage_* vars
                                           (no zparseopts, no docopt parsing)
```

### Components

- **`config/bin/xc-fabric`**: The executable script written in zsh with `usage zsh` shebang.
- **`usage` CLI**: Installed binary handling arg/flag parsing, formatted help text, and JSON spec generation.
- **`assets/integration/bin/xc-fabric.spec.ts`**: Integration test suite verifying subcommand execution and `#USAGE` examples.

## 4. Subcommand Dispatch & Variable Mapping

### 4.1 Flag Mapping

- **Boolean Flags**: `$usage_raw`, `$usage_copy`, `$usage_yes`, `$usage_no_preview`, `$usage_yt_timestamps`, `$usage_yt_comments`, `$usage_yt_metadata`, `$usage_yt_playlist`, `$usage_debug`.
- **String Flags**: `$usage_model`, `$usage_output`, `$usage_v`, `$usage_strategy`.

### 4.2 Positional Parameters & Dispatch

```zsh
case "${1:-}" in
  run)
    _xc_fabric_cmd_run "$usage_pattern" "$usage_url"
    ;;
  ls)
    _xc_fabric_cmd_ls
    ;;
  update)
    _xc_fabric_cmd_update
    ;;
  show)
    if [[ -z "$usage_pattern" ]]; then
      usage zsh "${0:a}" show --help >&2
      exit 1
    fi
    _xc_fabric_cmd_show "$usage_pattern"
    ;;
  strategies)
    _xc_fabric_cmd_strategies
    ;;
  scrape)
    if [[ -z "$usage_url" ]]; then
      usage zsh "${0:a}" scrape --help >&2
      exit 1
    fi
    _xc_fabric_cmd_scrape "$usage_url" "$usage_pattern"
    ;;
  '')
    _xc_fabric_interactive
    ;;
  *)
    usage zsh "${0:a}" --help >&2
    exit 1
    ;;
esac
```
